# Privacy policy: PHP2Shell Site Check

Last updated: 22 October 2026

PHP2Shell Site Check does not collect, store remotely, sell or share any data.

- **What it reads:** the HTTP response headers of pages you visit (and of same-site requests those pages make), and whether you focused a password or card-number field. It does not read what you type.
- **Where it goes:** nowhere. The extension makes no network requests. Each tab's verdict, the evidence headers behind it and the current page address are kept in the browser's in-memory session storage and are deleted when the tab closes or the browser exits.
- **Third parties:** none. No analytics, no telemetry, no remote code.
