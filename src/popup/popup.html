    About this check

    PHP2Shell (CVE-2026-109618 and CVE-2026-109619) lets an attacker run code on a PHP web server with a single request. Fixed in PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35. Older branches have no fix.

    This extension only reads the headers your browser already receives. It never probes servers. Most well-run sites hide their PHP version, and Linux distributions (including Red Hat-family servers, which can't always be recognized) often patch without changing it, so treat the result as a hint, not proof. A compromised page can hide the in-page warning; the toolbar badge can't be touched by the page.
